هدف تمرین

هدف این تمرین، پیاده‌سازی عملی یکی از الگوریتم‌های یادگیری ماشین است تا دانشجویان درک عملی از نحوه کار الگوریتم‌ها پیدا کنند.

گزینه‌های تمرین

دانشجویان باید یکی از گزینه‌های زیر را انتخاب کنند:

گزینه ۱: پیاده‌سازی رگرسیون خطی از صفر

  • پیاده‌سازی رگرسیون خطی ساده بدون استفاده از کتابخانه‌های ML
  • استفاده از گرادیان کاهشی برای بهینه‌سازی
  • نمایش نتایج با نمودار

گزینه ۲: پیاده‌سازی K-Means

  • پیاده‌سازی الگوریتم K-Means از صفر
  • استفاده از داده‌های مصنوعی یا واقعی
  • نمایش خوشه‌ها با نمودار

گزینه ۳: پیاده‌سازی KNN

  • پیاده‌سازی الگوریتم KNN
  • استفاده از داده‌های طبقه‌بندی (مثلاً Iris)
  • بررسی تأثیر مقدار K

جلسه ۱۱: آماده‌سازی مجموعه داده و پیش‌پردازش

اهداف یادگیری

  • آشنایی با مراحل آماده‌سازی داده
  • یادگیری تکنیک‌های پیش‌پردازش
  • درک اهمیت کیفیت داده
۸۰٪ زمان پروژه‌های ML صرف آماده‌سازی داده می‌شود!

مراحل اصلی:

  1. جمع‌آوری داده: از منابع مختلف
  2. بررسی اولیه: شناخت ساختار و کیفیت
  3. پاکسازی: رفع مشکلات داده
  4. تبدیل: آماده‌سازی برای مدل
  5. تقسیم:Train/Validation/Test

نکته مهم:

داده بد = مدل بد

"Garbage In, Garbage Out"

مقادیر از دست رفته (Missing Values):

  • حذف: حذف سطر یا ستون
  • جایگزینی: با میانگین، میانه، یا مد
  • پیش‌بینی: با مدل ML

روش‌های جایگزینی:

نوع داده روش پیشنهادی
عددی میانگین یا میانه
طبقه‌ای مد (بیشترین تکرار)
زمانی Interpolate

داده‌های تکراری:

  • شناسایی و حذف داده‌های تکراری
  • حذف سطرهای کاملاً یکسان
مقیاس‌گذاری = تبدیل ویژگی‌ها به محدوده یا توزیع مشخص

اهمیت:

  • بسیاری از الگوریتم‌ها به مقیاس حساس هستند
  • KNN، SVM، Neural Networks نیاز دارند
  • Linear Regression، Decision Tree نیاز ندارند

انواع مقیاس‌گذاری:

۱. استانداردسازی (Standardization):

x' = (x - μ) / σ

میانگین = ۰، انحراف معیار = ۱

۲. نرمال‌سازی (Min-Max Scaling):

x' = (x - min) / (max - min)

محدوده [0, 1]

۳. Robust Scaling:

x' = (x - median) / IQR

مقاوم در برابر نقاط پرت

مقایسه:

روش مزایا معایب
StandardScaler خوب برای توزیع نرمال حساس به پرت
MinMaxScaler محدوده مشخص حساس به پرت
RobustScaler مقاوم به پرت پیچیده‌تر

۱. Label Encoding:

تبدیل هر مقدار به یک عدد:

["red", "green", "blue"] → [0, 1, 2]

مشکل: مدل فکر می‌کند red < green < blue

۲. One-Hot Encoding:

یک ستون برای هر مقدار:

["red", "green", "blue"]

→ red: [1, 0, 0]

→ green: [0, 1, 0]

→ blue: [0, 0, 1]

۳. Ordinal Encoding:

برای ترتیب معنادار:

["low", "medium", "high"] → [0, 1, 2]

تقسیم داده به مجموعه‌های مجزا برای آموزش و ارزیابی

تقسیم استاندارد:

  • Train: 70-80%
  • Validation: 10-15%
  • Test: 10-15%

روش‌های تقسیم:

  • Random Split: تصادفی
  • Stratified Split: حفظ توزیع کلاس‌ها
  • Time-based Split: بر اساس زمان

نکته مهم:

هیچگاه مدل را با داده Test ارزیابی نکنید!

از Validation برای تنظیم استفاده کنید.

ایجاد ویژگی‌های جدید از ویژگی‌های موجود

روش‌ها:

  • Polynomial Features: x², x³, x₁x₂
  • Interaction Features: ترکیب ویژگی‌ها
  • Domain-specific: دانش تخصصی

مثال:

ویژگی‌های اولیه: قد، وزن

ویژگی جدید: BMI = وزن / قد²

مقدمه و اهمیت داده (۱۰ دقیقه):

با آمار شروع کنید: «۸۰٪ زمان پروژه‌های ML صرف آماده‌سازی داده می‌شود!» این خیلی مهم است. تأکید کنید که بهترین مدل هم اگر داده بد داشته باشد، نتیجه بد می‌دهد - این مثل این است که با ماشین معیوب مسابقه بدهید. مثال: اگر داده‌های آموزشی تبعیض داشته باشند (مثلاً فقط مردان)، مدل هم تبعیض یاد می‌گیرد.

پاکسازی داده (۸ دقیقه):

با مثال مقادیر از دست رفته شروع کنید: فرض کنید در یک فرم، خیلی‌ها شماره تماس را پر نکرده‌اند. چه کنیم؟ روش‌ها: حذف (اگر تعداد کم بود)، جایگزینی با میانگین (برای عدد)، یا پیش‌بینی با مدل (اگر داده مهم باشد). تأکید کنید که روش انتخابی به نوع داده و مقدار از دست رفته بستگی دارد.

مقیاس‌گذاری (۱۰ دقیقه):

با یک مثال ملموس: قد افراد ۱۵۰-۲۰۰ سانتی‌متر است، درآمد ۱-۱۰۰ میلیون تومان. اگر مدلی داشته باشیم، فکر می‌کند درآمد خیلی مهم‌تر است چون اعداد بزرگ‌تری دارد. مقیاس‌گذاری این را درست می‌کند. تفاوت استانداردسازی (میانگین ۰) و نرمال‌سازی (محدوده ۰-۱) را توضیح دهید. کدام را کی استفاده کنیم؟ نرمال‌سازی وقتی محدوده مشخص داریم، استانداردسازی وقتی توزیع نرمال می‌خواهیم.

کدگذاری (۶ دقیقه):

مثال رنگ‌ها: اگر بگوییم قرمز=۰، سبز=۱، آبی=۲، مدل فکر می‌کند قرمز < سبز < آبی - این اشتباه است. One-Hot Encoding این مشکل را حل می‌کند. اما اگر ترتیب معنادار داشته باشیم (کم=۰، متوسط=۱، زیاد=۲) می‌توانیم از Ordinal Encoding استفاده کنیم.

تقسیم داده (۶ دقیقه):

خیلی مهم: داده Test را کنار بگذارید و فقط در انتها استفاده کنید! مثال: دانش‌آموزی که تمام سؤال‌های امتحان را قبلاً دیده، نمی‌تواند نشان دهد که یاد گرفته. Validation برای تنظیم مدل است، Test برای ارزیابی نهایی. Stratified Split را توضیح دهید: وقتی کلاس‌های نامتعادل داریم (مثلاً ۹۵٪ منفی، ۵٪ مثبت)، باید توزیع را حفظ کنیم.

جمع‌بندی (۵ دقیقه):

خلاصه: داده خوب = مدل خوب. پاکسازی، مقیاس‌گذاری، کدگذاری، و تقسیم درست مراحل آماده‌سازی هستند. این مهارت با تمرین بهتر می‌شود. تکلیف: دانشجویان باید یک دیتاست پیدا کنند (مثلاً از Kaggle) و مراحل پیش‌پردازش را روی آن اجرا کنند.

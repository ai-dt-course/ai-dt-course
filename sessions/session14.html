جلسه ۱۴: شاخص‌های ارزیابی و انتخاب مدل

اهداف یادگیری

  • آشنایی با شاخص‌های ارزیابی
  • یادگیری انتخاب شاخص مناسب
  • درک مفهوم Trade-off

۱. MSE (Mean Squared Error):

MSE = 1/n × Σ(yi - ŷi)2
  • همیشه مثبت
  • به نقاط پرت حساس
  • یکای آن مجذور یکای اصلی

۲. RMSE (Root MSE):

RMSE = √MSE
  • هم‌یکا با متغیر خروجی
  • قابل فهم‌تر

۳. MAE (Mean Absolute Error):

MAE = 1/n × Σ|yi - ŷi|
  • کمتر حساس به پرت
  • یکای اصلی

۴. R² (Coefficient of Determination):

R² = 1 - SSres / SStot
  • بین ۰ و ۱
  • ۱ = مدل عالی
  • ۰ = مدل بد

Accuracy (دقت):

Accuracy = (TP + TN) / (TP + TN + FP + FN)

ماتریس سردرگمی (Confusion Matrix):

پیش‌بینی: مثبت پیش‌بینی: منفی
واقعی: مثبت TP (True Positive) FN (False Negative)
واقعی: منفی FP (False Positive) TN (True Negative)

مثال:

۱۰۰۰ نمونه: ۹۰۰ منفی، ۱۰۰ مثبت

مدل: ۸۵۰ TN، ۵۰ TP، ۵۰ FP، ۵۰ FN

Accuracy = (850+50)/1000 = 90%

Precision (دقت):

Precision = TP / (TP + FP)

از کسانی که مثبت گفتیم، چندتا واقعاً مثبت بودند؟

Recall (یادآوری):

Recall = TP / (TP + FN)

از کسانی که واقعاً مثبت بودند، چندتا را پیدا کردیم؟

مثال:

تشخیص سرطان:

  • می‌خواهیم همه سرطانی‌ها را پیدا کنیم → Recall بالا
  • می‌خواهیم اشتباهی سرطان نگوییم → Precision بالا
میانگین هارمونیک Precision و Recall
F1 = 2 × (Precision × Recall) / (Precision + Recall)

چرا میانگین هارمونیک؟

  • اگر یکی صفر باشد، F1 صفر می‌شود
  • هر دو باید بالا باشند

F-Beta:

Fβ = (1+β²) × (P×R) / (β²×P + R)
  • F0.5: Precision مهم‌تر
  • F2: Recall مهم‌تر

ROC Curve (Receiver Operating Characteristic):

نمودار True Positive Rate در مقابل False Positive Rate

TPR = TP / (TP + FN)
FPR = FP / (FP + TN)

AUC (Area Under Curve):

  • AUC = 1: مدل عالی
  • AUC = 0.5: مدل تصادفی
  • AUC < 0.5: بدتر از تصادفی

مزایا:

  • مقایسه مدل‌ها
  • انتخاب آستانه بهینه
  • کاربرد در داده نامتوازن
مشکل شاخص مناسب
داده متوازن Accuracy
داده نامتوازن Precision, Recall, F1
تشخیص همه موارد مثبت Recall
کاهش false positive Precision
مقایسه کلی مدل‌ها AUC-ROC

Trade-off:

Precision و Recall معمولاً متضاد هستند.

→ بسته به مشکل، یکی را انتخاب کنید.

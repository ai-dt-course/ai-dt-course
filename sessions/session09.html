جلسه ۹: دسته‌بندی و خوشه‌بندی

اهداف یادگیری

  • درک تفاوت دسته‌بندی و خوشه‌بندی
  • آشنایی با الگوریتم‌های دسته‌بندی
  • شناخت الگوریتم‌های خوشه‌بندی
دسته‌بندی: پیش‌بینی یک برچسب (کلاس) برای هر نمونه بر اساس ویژگی‌های آن.

انواع دسته‌بندی:

  • دو کلاسه (Binary): بله/خیر، spam/not spam
  • چند کلاسه (Multi-class): گربه/سگ/پرنده
  • چند برچسبه (Multi-label): یک نمونه چند برچسب دارد

مثال‌های کاربردی:

  • تشخیص ایمیل اسپم
  • تشخیص بیماری از علائم
  • تشخیص چهره
  • پیش‌بینی ریزش مشتریان

K-Nearest Neighbors (KNN)

"به همسایه‌هایت نگاه کن" - برچسب نمونه را طبق اکثریت همسایه‌های نزدیک تعیین می‌کنیم.

الگوریتم:

  1. فاصله نمونه جدید را با همه نمونه‌های آموزش محاسبه کن
  2. K همسایه نزدیک را پیدا کن
  3. برچسب اکثریت را به نمونه جدید بده

فرمول فاصله اقلیدسی:

d(x, y) = √Σ(xi - yi)²

مزایا و معایب:

مزایا معایب
ساده و قابل فهم کند در زمان پیش‌بینی
ندارد مرحله آموزش حساس به مقیاس ویژگی‌ها
طبیعی نیاز به تعیین K

رگرسیون لجستیک

استفاده از تابع لجستیک برای تبدیل خروجی خطی به احتمال

تابع لجستیک (Sigmoid):

σ(z) = 1 / (1 + e-z)

مدل:

P(y=1|x) = σ(wx + b) = 1 / (1 + e-(wx+b))

مرز تصمیم:

وقتی P > 0.5 → کلاس 1

وقتی P ≤ 0.5 → کلاس 0

مثال: تشخیص اسپم

x = تعداد کلمات مشکوک

اگر wx + b = 2 → P = 0.88 → اسپم

اگر wx + b = -1 → P = 0.27 → اسپم نیست

Support Vector Machine (SVM)

پیدا کردن ابرصفحه‌ای که بیشترین فاصله را بین کلاس‌ها دارد.

مفاهیم کلیدی:

  • Support Vectors: نمونه‌هایی که روی مرز هستند
  • Maximum Margin: بیشترین فاصله بین کلاس‌ها
  • Hyperplane: مرز تصمیم در فضای چند بعدی

فرمول:

w · x + b = 0

Kernel Trick:

استفاده از توابع هسته برای تبدیل فضا به فضای با بُعد بالاتر:

  • Linear Kernel
  • Polynomial Kernel
  • RBF (Gaussian) Kernel

مثال: تفکیک دایره‌ای از نقاط

با RBF Kernel می‌توان مرز دایره‌ای ایجاد کرد

درخت تصمیم

استفاده از قوانین if-then برای دسته‌بندی

مفاهیم:

  • Root: ریشه - اولین سوال
  • Node: هر سوال
  • Leaf: برگ - نتیجه نهایی
  • Split: تقسیم بر اساس یک ویژگی

معیارهای تقسیم:

  • Gini Impurity:
    • Gini = 1 - Σpi²
  • Entropy:
    • Entropy = -Σpi × log₂(pi)
  • Information Gain:
    • IG = Entropy(parent) - Weighted_Avg(Entropy(children))

مزایا و معایب:

مزایا معایب
قابل تفسیر مستعد بیش‌برازش
نیازی به مقیاس داده نیست ناپایدار (تغییر کم داده → تغییر زیاد درخت)
خوشه‌بندی: گروه‌بندی داده‌های مشابه بدون برچسب اولیه

تفاوت با دسته‌بندی:

دسته‌بندی خوشه‌بندی
یادگیری باناظر یادگیری بی‌ناظر
برچسب‌ها مشخص برچسب‌ها نامشخص
داده‌های برچسب‌گذاری شده فقط داده‌های خام

کاربردها:

  • سگمان‌بندی مشتریان
  • فشرده‌سازی تصویر
  • تشخیص ناهنجاری
  • تحلیل شبکه‌های اجتماعی

K-Means

تقسیم داده‌ها به K خوشه بر اساس فاصله از مراکز

الگوریتم:

  1. K نقطه تصادفی به عنوان مراکز (Centroids) انتخاب کن
  2. هر داده را به نزدیک‌ترین مرکز اختصاص بده
  3. مراکز را دوباره محاسبه کن (میانگین هر خوشه)
  4. تکرار ۲ و ۳ تا همگرایی

فرمول:

J = Σk Σi∈C_k ||xi - μk||²

که μk مرکز خوشه k است.

مزایا و معایب:

مزایا معایب
ساده و سریع نیاز به تعیین K
مقیاس‌پذیر حساس به نقطه اولیه
فرض کروی بودن خوشه‌ها

روش Elbow:

برای پیدا کردن K بهینه، مجموع فاصله‌های درون‌خوشه‌ای را برای Kهای مختلف رسم کنید. نقطه‌ای که کاهش آهسته می‌شود (آرنج) را انتخاب کنید.

DBSCAN

خوشه‌بندی بر اساس چگالی - خوشه‌ها مناطق با چگالی بالا هستند

مفاهیم:

  • Core Point: نقطه‌ای با حداقل MinPts همسایه در شعاع ε
  • Border Point: نقطه‌ای که هسته نیست ولی در همسایگی هسته است
  • Noise Point: نقطه‌ای که در هیچ خوشه‌ای نیست

پارامترها:

  • ε (eps): شعاع همسایگی
  • MinPts: حداقل نقاط برای هسته شدن

مزایا:

  • تعداد خوشه‌ها خودکار تعیین می‌شود
  • می‌تواند خوشه‌های شکل‌های مختلف را پیدا کند
  • نقاط نویز را تشخیص می‌دهد

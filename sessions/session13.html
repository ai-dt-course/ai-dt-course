جلسه ۱۳: بیش‌برازش و زیربرازش

اهداف یادگیری

  • درک مفهوم بیش‌برازش و زیربرازش
  • یادگیری روش‌های تشخیص و رفع
  • آشنایی با اعتبارسنجی

بیش‌برازش (Overfitting)

مدل داده‌های آموزش را حفظ می‌کند ولی روی داده‌های جدید ضعیف عمل می‌کند.
  • مدل خیلی پیچیده است
  • دسترسی به نویز داده‌ها
  • داده آموزش کم است

زیربرازش (Underfitting)

مدل خیلی ساده است و الگوهای مهم را هم یاد نمی‌گیرد.
  • مدل خیلی ساده است
  • آموزش کافی نیست

راه‌حل‌ها

  • Regularization: جریمه پارامترهای بزرگ
  • Dropout: غیرفعال کردن تصادفی نورون‌ها
  • Early Stopping: توقف زودهنگام
  • Cross-Validation: اعتبارسنجی متقاطع
  • Data Augmentation: افزایش داده

منحني یادگیری

  • Train Error ↓ + Test Error ↑ = Overfitting
  • Train Error ≈ Test Error + بالا = Underfitting
  • Train Error ≈ Test Error + پایین = Good Fit

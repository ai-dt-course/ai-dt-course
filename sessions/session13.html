جلسه ۱۳: بیش‌برازش و زیربرازش

اهداف یادگیری

  • درک مفهوم بیش‌برازش و زیربرازش
  • یادگیری روش‌های تشخیص و رفع
  • آشنایی با اعتبارسنجی
بیش‌برازش: مدل داده‌های آموزش را حفظ می‌کند ولی روی داده‌های جدید ضعیف عمل می‌کند.

علل:

  • مدل خیلی پیچیده است
  • دسترسی به نویز داده‌ها
  • داده آموزش کم است
  • آموزش بیش از حد

علائم:

  • دقت روی train بالا، روی test پایین
  • مدل جزئیات ریز داده‌ها را یاد می‌گیرد

مثال تصویری:

در طبقه‌بندی: مدل مرز پیچیده‌ای رسم می‌کند که نقاط را کاملاً جدا می‌کند.

→ روی داده جدید شکست می‌خورد

زیربرازش: مدل خیلی ساده است و الگوهای مهم را هم یاد نمی‌گیرد.

علل:

  • مدل خیلی ساده است
  • آموزش کافی نیست
  • ویژگی‌های ناکافی

علائم:

  • دقت روی train و test هر دو پایین
  • مدل الگوهای اصلی را یاد نمی‌گیرد

مثال:

استفاده از یک خط برای داده‌های منحنی

→ مدل توانایی کافی ندارد

رسم خطا بر حسب اندازه داده آموزش

تحلیل:

حالت Train Error Test Error راه‌حل
Overfitting پایین بالا Regularization, More data
Underfitting بالا بالا Complex model, More features
Good Fit پایین پایین ✓

۱. منظم‌سازی (Regularization):

  • L1 (Lasso): جریمه جمع قدرمطلق وزن‌ها
  • L2 (Ridge): جریمه مجذور وزن‌ها
  • Elastic Net: ترکیب L1 و L2

۲. Dropout:

در شبکه‌های عصبی: غیرفعال کردن تصادفی نورون‌ها در هنگام آموزش

۳. Early Stopping:

توقف آموزش وقتی خطای validation افزایش یافت

۴. افزایش داده (Data Augmentation):

  • چرخش، برش، تغییر رنگ تصاویر
  • Synonym replacement در متن

۵. کاهش پیچیدگی مدل:

  • کم کردن درخت در Decision Tree
  • کم کردن تعداد نورون‌ها
روشی برای ارزیابی عملکرد مدل با تقسیم داده به چند بخش

K-Fold Cross-Validation:

  1. داده را به K قسمت تقسیم کن
  2. K-1 قسمت برای آموزش
  3. ۱ قسمت برای تست
  4. این کار را K بار تکرار کن
  5. میانگین نتایج را بگیر

مزایا:

  • استفاده بهینه از داده
  • تخمین بهتر عملکرد
  • کاهش variance

انواع:

  • Stratified K-Fold: حفظ توزیع کلاس
  • Time Series Split: برای داده‌های زمانی
  • Leave-One-Out (LOO): K = n

مفهوم:

بخشی از داده که برای تنظیم هایپرپارامترها و انتخاب مدل استفاده می‌شود.

روش‌ها:

  • Holdout: تقسیم ساده (60/20/20)
  • K-Fold: تقسیم به K بخش
  • Stratified: حفظ توزیع

نکته مهم:

→ Test نباید در آموزش استفاده شود!

→ Validation برای تنظیم است

→ Test برای ارزیابی نهایی

جلسه ۱۳: بیش‌برازش و زیربرازش

اهداف یادگیری

  • درک مفهوم بیش‌برازش و زیربرازش
  • یادگیری روش‌های تشخیص و رفع
  • آشنایی با اعتبارسنجی
بیش‌برازش: مدل داده‌های آموزش را حفظ می‌کند ولی روی داده‌های جدید ضعیف عمل می‌کند.

علل:

  • مدل خیلی پیچیده است
  • دسترسی به نویز داده‌ها
  • داده آموزش کم است
  • آموزش بیش از حد

علائم:

  • دقت روی train بالا، روی test پایین
  • مدل جزئیات ریز داده‌ها را یاد می‌گیرد

مثال تصویری:

در طبقه‌بندی: مدل مرز پیچیده‌ای رسم می‌کند که نقاط را کاملاً جدا می‌کند.

→ روی داده جدید شکست می‌خورد

زیربرازش: مدل خیلی ساده است و الگوهای مهم را هم یاد نمی‌گیرد.

علل:

  • مدل خیلی ساده است
  • آموزش کافی نیست
  • ویژگی‌های ناکافی

علائم:

  • دقت روی train و test هر دو پایین
  • مدل الگوهای اصلی را یاد نمی‌گیرد

مثال:

استفاده از یک خط برای داده‌های منحنی

→ مدل توانایی کافی ندارد

رسم خطا بر حسب اندازه داده آموزش

تحلیل:

حالت Train Error Test Error راه‌حل
Overfitting پایین بالا Regularization, More data
Underfitting بالا بالا Complex model, More features
Good Fit پایین پایین ✓

۱. منظم‌سازی (Regularization):

  • L1 (Lasso): جریمه جمع قدرمطلق وزن‌ها
  • L2 (Ridge): جریمه مجذور وزن‌ها
  • Elastic Net: ترکیب L1 و L2

۲. Dropout:

در شبکه‌های عصبی: غیرفعال کردن تصادفی نورون‌ها در هنگام آموزش

۳. Early Stopping:

توقف آموزش وقتی خطای validation افزایش یافت

۴. افزایش داده (Data Augmentation):

  • چرخش، برش، تغییر رنگ تصاویر
  • Synonym replacement در متن

۵. کاهش پیچیدگی مدل:

  • کم کردن درخت در Decision Tree
  • کم کردن تعداد نورون‌ها
روشی برای ارزیابی عملکرد مدل با تقسیم داده به چند بخش

K-Fold Cross-Validation:

  1. داده را به K قسمت تقسیم کن
  2. K-1 قسمت برای آموزش
  3. ۱ قسمت برای تست
  4. این کار را K بار تکرار کن
  5. میانگین نتایج را بگیر

مزایا:

  • استفاده بهینه از داده
  • تخمین بهتر عملکرد
  • کاهش variance

انواع:

  • Stratified K-Fold: حفظ توزیع کلاس
  • Time Series Split: برای داده‌های زمانی
  • Leave-One-Out (LOO): K = n

مفهوم:

بخشی از داده که برای تنظیم هایپرپارامترها و انتخاب مدل استفاده می‌شود.

روش‌ها:

  • Holdout: تقسیم ساده (60/20/20)
  • K-Fold: تقسیم به K بخش
  • Stratified: حفظ توزیع

نکته مهم:

→ Test نباید در آموزش استفاده شود!

→ Validation برای تنظیم است

→ Test برای ارزیابی نهایی

مقدمه و مفهوم بیش‌برازش (۸ دقیقه):

با یک تشبیه شروع کنید: بیش‌برازش مثل دانش‌آموزی است که حفظ می‌کند نه یاد می‌گیرد. امتحان را که عیناً سؤال‌های تمرین باشد می‌تواند جواب دهد، اما سؤال جدید را نه! مدل هم همین‌طور است - اگر داده‌های آموزش را حفظ کند، روی داده جدید شکست می‌خورد. مثال: اگر درخت تصمیم خیلی عمیق باشد، می‌تواند هر داده آموزت را درست分类 کند ولی داده جدید را نه.

زیربرازش (۶ دقیقه):

زیربرازش برعکس است - مدل خیلی ساده است. مثال: می‌خواهیم یک منحنی را با یک خط فیت کنیم - هر چقدر خط بکشیم نمی‌تواند منحنی را دنبال کند. این هم بد است چون مدل الگوهای اصلی را هم یاد نمی‌گیرد. تعادل: مدلی که به اندازه کافی پیچیده باشد (نه خیلی ساده، نه خیلی پیچیده) - این مهم‌ترین چالش در ML است.

منحني یادگیری (۸ دقیقه):

Learning Curves را روی تخته رسم کنید: محور x اندازه داده، محور y خطا. بیش‌برازش: خطای train پایین، خطای test بالا - فاصله زیاد. زیربرازش: هر دو خطا بالا. Good fit: هر دو خطا پایین و نزدیک به هم. این نمودار به شما می‌گوید که مشکل کجاست و چه کاری باید انجام دهید.

روش‌های جلوگیری (۱۰ دقیقه):

Regularization: مثل این است که به مدل بگوییم «ساده‌تر باش». L1 برخی وزن‌ها را صفر می‌کند (انتخاب ویژگی)، L2 همه را کوچک می‌کند. Dropout: در شبکه عصبی، هر بار نورون‌های تصادفی را خاموش کنیم - این باعث می‌شود شبکه یاد نگیرد به یک نورون خاص وابسته باشد. Early Stopping: وقتی خطای validation شروع به زیاد شدن کرد، آموزش را متوقف کنیم - این خیلی مهم است!

اعتبارسنجی (۸ دقیقه):

K-Fold Cross-Validation را توضیح دهید: داده را به ۵ قسمت تقسیم کن، ۴ تا را آموزش بده، ۱ تا را تست کن، ۵ بار تکرار کن، میانگین بگیر. مزیت: همه داده‌ها هم train هم test می‌بینند - تخمین بهتری از عملکرد واقعی می‌دهد. معمولاً K=5 یا K=10 استفاده می‌شود. Stratified K-Fold برای داده نامتوازن مهم است.

جمع‌بندی (۵ دقیقه):

خلاصه: بیش‌برازش = مدل پیچیده، زیربرازش = مدل ساده. از Learning Curves برای تشخیص استفاده کنید. راه‌حل‌ها: Regularization، Dropout، Early Stopping، داده بیشتر. از Cross-Validation برای ارزیابی بهتر استفاده کنید. تکلیف: دانشجویان باید یک مثال بسازند و نشان دهند که چطور با تغییر پیچیدگی مدل، بیش‌برازش یا زیربرازش ایجاد می‌شود.

فصل سیزدهم: بیش‌برازش و زیربرازش

۱۳.۱ بیش‌برازش (Overfitting)

بیش‌برازش زمانی رخ می‌دهد که مدل داده‌های آموزش را حفظ می‌کند ولی روی داده‌های جدید ضعیف عمل می‌کند.

علل بیش‌برازش:

  • مدل خیلی پیچیده است
  • مدل به نویز داده‌ها دسترسی پیدا می‌کند
  • داده آموزش کم است
  • آموزش بیش از حد (بیش از حد epochs)

علائم بیش‌برازش:

  • دقت روی داده آموزش بالا، روی داده تست پایین
  • مدل جزئیات ریز داده‌ها را یاد می‌گیرد

مثال:

در طبقه‌بندی، مدل مرز پیچیده‌ای رسم می‌کند که نقاط آموزش را کاملاً جدا می‌کند، اما روی داده جدید شکست می‌خورد.

۱۳.۲ زیربرازش (Underfitting)

زیربرازش زمانی رخ می‌دهد که مدل خیلی ساده است و الگوهای مهم را هم یاد نمی‌گیرد.

علل زیربرازش:

  • مدل خیلی ساده است
  • آموزش کافی نیست
  • ویژگی‌های ناکافی

علائم زیربرازش:

  • دقت روی داده آموزش و تست هر دو پایین
  • مدل الگوهای اصلی را یاد نمی‌گیرد

مثال:

استفاده از یک خط برای داده‌های منحنی - مدل توانایی کافی ندارد.

۱۳.۳ منحنی یادگیری (Learning Curves)

منحنی یادگیری نمودار خطا بر حسب اندازه داده آموزش است.

تحلیل منحنی یادگیری:

حالت خطای Train خطای Test راه‌حل
بیش‌برازش پایین بالا منظم‌سازی، داده بیشتر
زیربرازش بالا بالا مدل پیچیده‌تر، ویژگی بیشتر
برازش خوب پایین پایین ✓

۱۳.۴ روش‌های جلوگیری از بیش‌برازش

۱. منظم‌سازی (Regularization):

  • L1 (Lasso): جریمه جمع قدرمطلق وزن‌ها
  • L2 (Ridge): جریمه مجذور وزن‌ها
  • Elastic Net: ترکیب L1 و L2

۲. Dropout:

در شبکه‌های عصبی: غیرفعال کردن تصادفی نورون‌ها در هنگام آموزش.

۳. Early Stopping:

توقف آموزش وقتی خطای validation افزایش یافت.

۴. افزایش داده (Data Augmentation):

  • چرخش، برش، تغییر رنگ تصاویر
  • جایگزینی مترادف در متن

۵. کاهش پیچیدگی مدل:

  • کم کردن عمق درخت در Decision Tree
  • کم کردن تعداد نورون‌ها در شبکه عصبی

۱۳.۵ اعتبارسنجی متقاطع (Cross-Validation)

اعتبارسنجی متقاطع روشی برای ارزیابی عملکرد مدل با تقسیم داده به چند بخش است.

K-Fold Cross-Validation:

  1. داده را به K قسمت تقسیم کن
  2. K-1 قسمت برای آموزش
  3. ۱ قسمت برای تست
  4. این کار را K بار تکرار کن
  5. میانگین نتایج را بگیر

مزایا:

  • استفاده بهینه از داده
  • تخمین بهتر عملکرد واقعی
  • کاهش واریانس تخمین

انواع:

  • Stratified K-Fold: حفظ توزیع کلاس
  • Time Series Split: برای داده‌های زمانی
  • Leave-One-Out: K = n

۱۳.۶ اعتبارسنجی (Validation)

اعتبارسنجی بخشی از داده است که برای تنظیم هایپرپارامترها و انتخاب مدل استفاده می‌شود.

روش‌های اعتبارسنجی:

  • Holdout: تقسیم ساده (مثلاً 60/20/20)
  • K-Fold: تقسیم به K بخش
  • Stratified: حفظ توزیع کلاس

نکته مهم:

  • داده Test نباید در آموزش استفاده شود!
  • داده Validation برای تنظیم مدل استفاده می‌شود
  • داده Test برای ارزیابی نهایی است

خلاصه فصل:

  1. بیش‌برازش = مدل پیچیده، زیربرازش = مدل ساده
  2. از Learning Curves برای تشخیص مشکل استفاده کنید
  3. راه‌حل‌ها: منظم‌سازی، Dropout، Early Stopping، داده بیشتر
  4. Cross-Validation تخمین بهتری از عملکرد واقعی می‌دهد
  5. داده Test فقط برای ارزیابی نهایی است

تمرین‌های خودآزمایی:

  1. بیش‌برازش چیست و چه عللی دارد؟
  2. چگونه می‌توان بیش‌برازش را تشخیص داد؟
  3. تفاوت L1 و L2 regularization چیست؟
  4. چرا Early Stopping مهم است؟
  5. یک مثال از زیربرازش بزنید

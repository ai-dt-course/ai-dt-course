جلسه ۶: رگرسیون و مسائل ارضای محدودیت

رگرسیون (Regression): تکنیک یادگیری ماشین برای پیش‌بینی یک مقدار پیوسته (عدد) بر اساس ورودی‌ها.

تفاوت رگرسیون و طبقه‌بندی:

ویژگی رگرسیون طبقه‌بندی
خروجی عدد پیوسته برچسب گسسته
مثال قیمت خانه اسپم/غیراسپم
روش ارزیابی MSE، MAE، R² Accuracy، F1

کاربردهای رایج رگرسیون:

  • پیش‌بینی قیمت خانه: بر اساس متراژ، تعداد اتاق، موقعیت، سن ساختمان
  • پیش‌بینی فروش: بر اساس هزینه تبلیغات، فصل، قیمت
  • پیش‌بینی مصرف برق: بر اساس ساعت روز، فصل، دما
  • پیش‌بینی دما: بر اساس داده‌های تاریخی هواشناسی
  • پیش‌بینی حقوق: بر اساس تحصیلات، تجربه، شهر
  • پیش‌بینی رشد: رشد جمعیت، رشد اقتصادی

چرا رگرسیون مهم است؟

بسیاری از مسائل واقعی کسب‌وکار به پیش‌بینی عدد نیاز دارند:

  • مدیر مالی: «فروش ماه بعد چقدر خواهد بود؟»
  • مدیر تولید: «چقدر باید تولید کنیم؟»
  • کارشناس بانک: «چه مبلغ وام بدهیم؟»
  • مهندس برق: «مصرف برق فردا چقدر است؟»

ساده‌ترین نوع رگرسیون که فقط یک متغیر ورودی دارد. مدل یک خط راست است.

y = w·x + b

اجزای فرمول:

نماد نام فارسی توضیح
y متغیر وابسته خروجی - مقداری که می‌خواهیم پیش‌بینی کنیم
x متغیر مستقل ورودی - ویژگی
w وزن (Weight) شیب خط - نشان‌دهنده تأثیر x بر y
b بایاس (Bias) عرض از مبدأ - مقدار y وقتی x=0

مثال عددی دقیق - پیش‌بینی قیمت خانه:

فرض کنید:

  • هر متر مربع = ۵۰۰ هزار تومان (w = 500,000)
  • قیمت پایه (زمین) = ۵۰ میلیون تومان (b = 50,000,000)

پیش‌بینی قیمت‌ها:

متراژ (x) محاسبه قیمت پیش‌بینی (y)
۵۰ متر 500,000×50 + 50,000,000 ۷۵ میلیون
۱۰۰ متر 500,000×100 + 50,000,000 ۱۰۰ میلیون
۲۰۰ متر 500,000×200 + 50,000,000 ۱۵۰ میلیون

روش کمترین مربعات (Ordinary Least Squares - OLS):

برای پیدا کردن بهترین w و b، خطای هر نقطه را محاسبه می‌کنیم:

w = Σ(xi - x̄)(yi - ȳ) / Σ(xi - x̄)2
b = ȳ - w·x̄

تابع هزینه MSE:

MSE = (1/n) · Σ(yi - ŷi)²

ما می‌خواهیم MSE را کمینه کنیم. این کار با گرادیان کاهشی (Gradient Descent) یا حل تحلیلی (OLS) انجام می‌شود.

محدودیت‌های رگرسیون خطی ساده:

  • فقط یک ویژگی دارد (در عمل معمولاً چندین ویژگی داریم)
  • فرض رابطه خطی (واقعیت ممکن است غیرخطی باشد)
  • حساس به نقاط پرت (Outliers)
  • فرض نرمال بودن باقیمانده‌ها

وقتی چندین ویژگی برای پیش‌بینی داریم، از رگرسیون چندگانه استفاده می‌کنیم. این رایج‌ترین نوع رگرسیون در عمل است.

y = w1x1 + w2x2 + ... + wnxn + b

یا به صورت برداری:

y = WTX + b

مثال کامل - پیش‌بینی قیمت خانه:

پیش‌بینی قیمت با ۴ ویژگی:

  • x1 = متراژ (هر متر = ۵۰۰ هزار تومان) → w1 = 500,000
  • x2 = تعداد اتاق (هر اتاق = ۱۰ میلیون) → w2 = 10,000,000
  • x3 = سن ساختمان (هر سال = -۵۰۰ هزار) → w3 = -500,000
  • x4 = پارکینگ (هر پارکینگ = ۲۰ میلیون) → w4 = 20,000,000
  • b = ۵۰ میلیون (قیمت پایه)

برای خانه ۱۰۰ متر، ۳ اتاق، ۱۰ سال ساخت، با پارکینگ:

قیمت = 500,000×100 + 10,000,000×3 - 500,000×10 + 20,000,000×1 + 50,000,000

= 50,000,000 + 30,000,000 - 5,000,000 + 20,000,000 + 50,000,000

= 145,000,000 تومان

ماتریس طراحی (Design Matrix):

اگر n نمونه داده و d ویژگی داشته باشیم، ماتریس X به این شکل است:

X = [[1, x1(1), x2(1), ..., xd(1)],
   [1, x1(2), x2(2), ..., xd(2)],
   ...,
   [1, x1(n), x2(n), ..., xd(n)]]
شکل: n × (d+1)

حل با OLS (به صورت ماتریسی):

W = (XTX)-1 XTy
هشدار: وقتی ویژگی‌ها زیاد هستند یا همبستگی بین آنها بالاست، ماتریس XTX ممکن است معکوس‌پذیر نباشد. در این موارد از رگرسیون ریج استفاده می‌شود.

تفسیر ضرایب:

هر وزن wi نشان می‌دهد:

  • اگر wi مثبت باشد: افزایش xi باعث افزایش y می‌شود
  • اگر wi منفی باشد: افزایش xi باعث کاهش y می‌شود
  • اگر wi نزدیک صفر باشد: xi تأثیر کمی بر y دارد
مثال تفسیر: وزن سن ساختمان = -500,000 یعنی «هر سال سن بیشتر، ۵۰۰ هزار تومان قیمت کمتر می‌شود» (با فرض ثابت بودن بقیه).

وقتی رابطه بین متغیرها غیرخطی است، از چندجمله‌ای‌ها استفاده می‌کنیم.

درجه ۲ (Quadratic):

y = w0 + w1x + w2x2

درجه ۳ (Cubic):

y = w0 + w1x + w2x2 + w3x3

درجه k عمومی:

y = Σi=0k wixi

مثال واقعی - رابطه سن خودرو و قیمت:

قیمت خودرو با افزایش سن کم می‌شود، اما نه به صورت خطی:

قیمت = 50,000,000 - 2,000,000·x + 50,000·x²

در اینجا x = سن خودرو به سال

  • سال اول: ۵۰ میلیون - ۲ میلیون + ۵۰ هزار = ≈ ۴۸ میلیون
  • سال دوم: ۵۰ میلیون - ۴ میلیون + ۲۰۰ هزار = ≈ ۴۶.۲ میلیون
  • سال پنجم: ۵۰ میلیون - ۱۰ میلیون + ۱.۲۵ میلیون = ≈ ۴۱.۲۵ میلیون

نکات مهم:

  • درجه بالا = پیچیدگی بیشتر = خطر بیش‌برازش
  • همیشه از اعتبارسنجی متقاطع استفاده کنید
  • درجه ۲-۳ معمولاً کافی است
  • اگر درجه بالا نیاز دارید، معمولاً بهتر است از شبکه عصبی استفاده کنید

تبدیل به رگرسیون خطی:

جالب است که رگرسیون پلی‌نومیال در واقع یک رگرسیون خطی است، با این تفاوت که ستون‌های جدید (x²، x³، ...) به ماتریس طراحی اضافه می‌شوند:

x → [x, x², x³]
منظم‌سازی (Regularization): تکنیکی برای جلوگیری از بیش‌برازش با اضافه کردن جریمه به وزن‌های بزرگ.

مشکل بیش‌برازش در رگرسیون:

وقتی مدل روی داده آموزش خوب است ولی روی داده جدید بد. این معمولاً وقتی رخ می‌دهد که ویژگی‌های زیادی داریم یا داده کم است.

۵.۱ رگرسیون ریج (Ridge Regression) - منظم‌سازی L2:

Loss = MSE + αΣwi2
  • جریمه: مجذور وزن‌ها
  • وزن‌ها را کوچک می‌کند ولی هرگز صفر نمی‌کند
  • مناسب وقتی همه ویژگی‌ها مهم هستند
  • مقاوم‌تر در برابر همبستگی بین ویژگی‌ها

۵.۲ رگرسیون لاسو (Lasso Regression) - منظم‌سازی L1:

Loss = MSE + αΣ|wi|
  • جریمه: قدرمطلق وزن‌ها
  • برخی وزن‌ها را دقیقاً صفر می‌کند
  • انتخاب ویژگی خودکار انجام می‌دهد
  • مناسب وقتی تعداد کمی از ویژگی‌ها واقعاً مهم هستند

۵.۳ Elastic Net - ترکیب:

Loss = MSE + α1Σ|wi| + α2Σwi2
  • ترکیب مزایای L1 و L2
  • انتخاب ویژگی + کوچک کردن وزن‌ها
  • در عمل بسیار محبوب است

پارامتر α (اهمیت منظم‌سازی):

  • α = 0: بدون منظم‌سازی (رگرسیون معمولی)
  • α کوچک: منظم‌سازی ملایم
  • α بزرگ: منظم‌سازی شدید (مدل ساده‌تر ولی ممکن است زیربرازش کند)

α معمولاً با Cross Validation تنظیم می‌شود.

۶.۱ رگرسیون درخت تصمیم:

درخت تصمیم که خروجی آن یک عدد است. قابل فهم و تفسیرپذیر.

  • غیرخطی بودن طبیعی
  • نیازی به مقیاس‌گذاری ندارد
  • خطر بیش‌برازش اگر عمق زیاد باشد

۶.۲ Random Forest Regression:

ترکیب چند درخت تصمیم برای کاهش بیش‌برازش.

۶.۳ SVR (Support Vector Regression):

نسخه رگرسیون SVM با استفاده از Kernel.

  • مناسب برای روابط پیچیده غیرخطی
  • مقاوم در برابر نقاط پرت

۶.۴ XGBoost:

الگوریتم gradient boosting که در مسابقات Kaggle بسیار موفق بوده.

جدول مقایسه:

روش رابطه سرعت دقت تفسیرپذیری
Linear خطی خیلی سریع متوسط عالی
Polynomial غیرخطی سریع خوب خوب
Ridge/Lasso خطی سریع خوب خوب
Decision Tree غیرخطی سریع خوب عالی
Random Forest غیرخطی متوسط خیلی خوب ضعیف
XGBoost غیرخطی متوسط عالی ضعیف
Neural Network هر رابطه کند عالی ضعیف (جعبه سیاه)
CSP (Constraint Satisfaction Problem): مسائلی که در آنها باید متغیرها را طوری مقداردهی کنیم که تمام محدودیت‌ها برآورده شوند.

اجزای CSP:

  • متغیرها (Variables): X = {X1, X2, ..., Xn
  • دامنه‌ها (Domains): D = {D1, D2, ..., Dn} - مقادیر ممکن برای هر متغیر
  • محدودیت‌ها (Constraints): C = {C1, C2, ..., Cm} - شرایطی که باید برقرار باشند

مثال ۱: زمان‌بندی امتحانات

متغیرها: امتحانات ریاضی، فیزیک، شیمی، ادبیات

دامنه: روزهای هفته (شنبه، یکشنبه، دوشنبه، سه‌شنبه)

محدودیت‌ها:

  • دانشجو نباید همزمان دو امتحان داشته باشد
  • امتحان ریاضی و فیزیک در یک روز نباشند
  • هر روز حداکثر ۲ امتحان

مثال ۲: سودوکو (Sudoku)

متغیرها: ۸۱ خانه جدول

دامنه: اعداد ۱ تا ۹

محدودیت‌ها:

  • در هر ردیف: اعداد ۱-۹ یکبار
  • در هر ستون: اعداد ۱-۹ یکبار
  • در هر مربع ۳×۳: اعداد ۱-۹ یکبار

مثال ۳: جدول زمان‌بندی کلاس‌ها

متغیرها: کلاس‌های درس (A, B, C, D)

دامنه: روزها و ساعات مختلف

محدودیت‌ها:

  • هیچ استادی همزمان دو کلاس نداشته باشد
  • کلاس A قبل از کلاس B باشد
  • هیچ کلاسی در ساعت ناهار نباشد

انواع محدودیت‌ها:

۱. محدودیت‌های یگانه (Unary):

مربوط به یک متغیر. مثال: X1 باید زوج باشد.

۲. محدودیت‌های دودویی (Binary):

مربوط به دو متغیر. مثال: X1 ≠ X2.

۳. محدودیت‌های چندتایی (Higher-order):

مربوط به چند متغیر. مثال: X1 + X2 + X3 < 10.

الگوریتم‌های حل CSP:

۱. Backtracking Search:

جستجوی عمقی با بازگشت. وقتی به بن‌بست می‌رسد، به عقب برمی‌گردد.

۲. Arc Consistency (AC-3):

قبل از شروع جستجو، دامنه‌ها را کوچک‌تر می‌کند. متغیرهایی که نمی‌توانند محدودیت‌ها را برآورده کنند حذف می‌شوند.

۳. Forward Checking:

وقتی مقدار یک متغیر را تعیین می‌کنیم، دامنه متغیرهای مرتبط را به‌روز می‌کنیم.

۴. Min-Conflicts:

با مقدار اولیه تصادفی شروع می‌کند و به صورت تکراری متغیری را که بیشترین تعارض را دارد تغییر می‌دهد.

۵. Genetic Algorithms:

الهام از تکامل طبیعی - انتخاب، ترکیب و جهش.

کاربردهای CSP در یادگیری ماشین:

اگرچه CSP یک مفهوم کلاسیک AI است، در ML نیز کاربردهای مهمی دارد:
  • انتخاب ویژگی: بهترین زیرمجموعه ویژگی‌ها را پیدا کنید (با محدودیت تعداد)
  • تنظیم ابرپارامترها: ترکیب بهینه ابرپارامترها
  • یادگیری ساختار: در شبکه‌های بیز، ساختار بهینه را پیدا کنید
  • AutoML: انتخاب خودکار مدل، ویژگی و ابرپارامتر
مقدمه و تعریف رگرسیون (۸ دقیقه):

با یک مثال ساده شروع کنید: «اگر بخواهیم قیمت یک خانه را پیش‌بینی کنیم، چه اطلاعاتی لازم داریم؟». دانشجویان می‌گویند: متراژ، تعداد اتاق، محله. این دقیقاً رگرسیون است - یعنی از چند ورودی (ویژگی) برای پیش‌بینی یک خروجی (قیمت) استفاده می‌کنیم. تأکید کنید که تفاوت رگرسیون و طبقه‌بندی در این است که خروجی رگرسیون یک عدد است، نه یک کلاس یا برچسب. مثال‌های ملموس ایرانی مثل پیش‌بینی قیمت مسکن یا قیمت طلا مفید هستند.

انواع رگرسیون (۵ دقیقه):

یک نمودار درختی ساده بکشید که انواع رگرسیون را نشان دهد. رگرسیون خطی ساده مثل پیش‌بینی قد بر اساس سن - یک خط راست. رگرسیون چندگانه چند ویژگی دارد. رگرسیون پلی‌نومیال برای منحنی‌ها. رگرسیون ریج و لاسو برای جلوگیری از مشکل بیش‌برازش. این تنوع نشان می‌دهد که بسته به نوع داده، روش مناسب متفاوت است.

رگرسیون خطی ساده (۱۲ دقیقه):

با فرمول y = wx + b شروع کنید. w یعنی شیب (weight)، b یعنی عرض از مبدأ (bias). با یک مثال ملموس توضیح دهید: فرض کنید می‌خواهیم قیمت خانه را بر اساس متراژ پیش‌بینی کنیم. اگر هر متر ۵۰۰ هزار تومان باشد و قیمت پایه ۵۰ میلیون، خانه ۱۰۰ متری چقدر می‌شود؟ دانشجویان می‌توانند حساب کنند. سپس روش کمترین مربعات را به صورت شهودی توضیح دهید: خطی که فاصله نقاط تا خط کمترین باشد. از تخته برای رسم استفاده کنید.

رگرسیون چندگانه (۸ دقیقه):

این مهم‌ترین نوع رگرسیون در عمل است. مثال خانه را توسعه دهید: حالا متراژ، تعداد اتاق، و سن ساختمان را داریم. هر کدام وزن متفاوتی دارند - مثلاً متراژ مهم‌تر از سن. این وزن‌ها را مدل از داده یاد می‌گیرد. نکته مهم: وقتی ویژگی‌های زیادی داریم، ممکن است مدل بیش‌برازش کند - برای همین رگرسیون ریج و لاسو به کمک می‌آیند. تفسیر ضرایب را با یک مثال ساده توضیح دهید.

رگرسیون ریج و لاسو (۵ دقیقه):

منظم‌سازی را با یک مثال ساده توضیح دهید: اگر مدلی دارید که روی داده‌های آموزش عالی عمل می‌کند اما روی داده‌های جدید بد، یعنی بیش‌برازش کرده. ریج و لاسو جریمه‌ای اضافه می‌کنند که مدل را ساده‌تر نگه می‌دارد. تفاوت: ریج وزن‌ها را کوچک می‌کند ولی صفر نمی‌کند، لاسو برخی را کاملاً صفر می‌کند (انتخاب ویژگی خودکار). اگر دانشجویان مهندسی هستند، مفهوم L1 و L2 norm را با نرم اقلیدسی مقایسه کنید.

مسائل ارضای محدودیت (CSP) (۱۰ دقیقه):

این بخش کمی متفاوت است چون CSP یک مفهوم کلاسیک AI است. با یک مثال ملموس شروع کنید: زمان‌بندی امتحانات. هر امتحان باید در یک زمان و روز خاص برگزار شود، اما دانشجویان نباید همزمان دو امتحان داشته باشند. این یک CSP است. متغیرها = امتحانات، دامنه = زمان‌ها، محدودیت‌ها = تداخل نداشتن. الگوریتم backtracking را توضیح دهید: یکی را انتخاب کن، اگر به مشکل خوردی برگرد و دیگری را امتحان کن. ارتباط CSP با ML را در پایان توضیح دهید.

جمع‌بندی (۲ دقیقه):

خلاصه: رگرسیون برای پیش‌بینی اعداد است، انواع مختلفی دارد، و در عمل رگرسیون چندگانه بیشتر استفاده می‌شود. CSP برای مسائل بهینه‌سازی با محدودیت است. تکلیف: دانشجویان باید یک مثال از رگرسیون در زندگی روزمره پیدا کنند. از آنها بخواهید فکر کنند: وزن‌های مدل چگونه از داده یاد گرفته می‌شوند؟ این سؤال جلسه بعد را Prequel می‌کند.

فصل ششم: رگرسیون و مسائل ارضای محدودیت

۶.۱ رگرسیون چیست؟

رگرسیون تکنیکی از یادگیری ماشین برای پیش‌بینی یک مقدار پیوسته است. برخلاف طبقه‌بندی (که خروجی آن یک برچسب است)، خروجی رگرسیون یک عدد پیوسته است.

کاربردهای رایج:

  • پیش‌بینی قیمت خانه بر اساس متراژ، تعداد اتاق، موقعیت
  • پیش‌بینی دمای فردا بر اساس داده‌های تاریخی
  • پیش‌بینی میزان فروش بر اساس هزینه تبلیغات
  • پیش‌بینی مصرف برق بر اساس ساعت روز و فصل

۶.۲ رگرسیون خطی ساده

ساده‌ترین نوع رگرسیون که فقط یک متغیر ورودی دارد. مدل یک خط راست است.

فرمول: y = w·x + b

که y خروجی، x ورودی، w وزن و b بایاس است.

روش کمترین مربعات (OLS):

برای پیدا کردن بهترین w و b، مجموع مربعات خطا کمینه می‌شود:

MSE = (1/n) · Σ(yi - ŷi)²

۶.۳ رگرسیون خطی چندگانه

وقتی چندین ویژگی برای پیش‌بینی داریم، از رگرسیون چندگانه استفاده می‌کنیم.

فرمول: y = w1x1 + w2x2 + ... + wnxn + b

یا به صورت برداری: y = WTX + b

حل ماتریسی:

W = (XTX)-1 XTy

۶.۴ رگرسیون پلی‌نومیال

برای مدل کردن روابط غیرخطی از چندجمله‌ای‌ها استفاده می‌شود:

y = w0 + w1x + w2x² + w3x³ + ...

نکته مهم:

استفاده از درجه بالای چندجمله‌ای ممکن است باعث بیش‌برازش شود.

۶.۵ منظم‌سازی (Regularization)

برای جلوگیری از بیش‌برازش، تکنیک‌های منظم‌سازی استفاده می‌شود:

رگرسیون ریج (Ridge) - منظم‌سازی L2:

Loss = MSE + αΣwi²

وزن‌ها را به سمت صفر می‌برد ولی صفر نمی‌کند.

رگرسیون لاسو (Lasso) - منظم‌سازی L1:

Loss = MSE + αΣ|wi|

برخی وزن‌ها را دقیقاً صفر می‌کند (انتخاب ویژگی).

Elastic Net:

ترکیب L1 و L2.

۶.۶ مسائل ارضای محدودیت (CSP)

CSP مسائلی هستند که در آنها باید متغیرها را طوری مقداردهی کنیم که محدودیت‌ها برآورده شوند.

اجزای CSP:

  • متغیرها: X = {X1, X2, ..., Xn
  • دامنه‌ها: D = {D1, D2, ..., Dn
  • محدودیت‌ها: C = {C1, C2, ..., Cm

مثال: زمان‌بندی امتحانات

  • متغیرها: امتحانات ریاضی، فیزیک، شیمی
  • دامنه: روزهای هفته
  • محدودیت: دو امتحان همزمان نباشند

الگوریتم‌های حل CSP:

  • Backtracking: جستجوی عمقی با بازگشت
  • Arc Consistency: سازگاری قوس
  • Forward Checking: بررسی پیشرو
  • Min-Conflicts: کمینه کردن تعارضات
  • Genetic Algorithms: الگوریتم ژنتیک

کاربرد CSP در ML:

CSP در یادگیری ماشین نیز کاربرد دارد:

  • انتخاب ویژگی (Feature Selection)
  • تنظیم ابرپارامترها (Hyperparameter Tuning)
  • AutoML
  • یادگیری ساختار شبکه‌های بیز

خلاصه فصل:

  1. رگرسیون برای پیش‌بینی مقادیر پیوسته استفاده می‌شود
  2. رگرسیون خطی ساده، چندگانه و پلی‌نومیال انواع مختلفی هستند
  3. ریج و لاسو برای جلوگیری از بیش‌برازش استفاده می‌شوند
  4. CSP برای مسائل بهینه‌سازی با محدودیت کاربرد دارد
  5. CSP در مسائل پیچیده ML مانند AutoML نیز استفاده می‌شود

تمرین‌های خودآزمایی:

  1. یک مثال از رگرسیون در زندگی روزمره پیدا کنید
  2. تفاوت رگرسیون خطی ساده و چندگانه را توضیح دهید
  3. چرا از منظم‌سازی استفاده می‌کنیم؟
  4. تفاوت L1 و L2 regularization چیست؟
  5. یک مثال CSP از زندگی روزمره بنویسید
  6. چگونه می‌توان از CSP در مسئله انتخاب ویژگی استفاده کرد؟

جلسه ۶: رگرسیون و مسائل ارضای محدودیت

اهداف یادگیری

  • درک مفهوم رگرسیون و انواع آن
  • آشنایی با رگرسیون خطی ساده و چندگانه
  • شناخت مسائل ارضای محدودیت (CSP)
رگرسیون: پیش‌بینی یک مقدار پیوسته بر اساس ورودی‌ها.

رگرسیون یکی از مهم‌ترین تکنیک‌های یادگیری ماشین است که برای پیش‌بینی مقادیر پیوسته استفاده می‌شود. برخلاف طبقه‌بندی که خروجی آن یک برچسب یا کلاس است، خروجی رگرسیون یک عدد پیوسته است.

مثال‌های کاربردی:

  • پیش‌بینی قیمت خانه بر اساس متراژ، تعداد اتاق، موقعیت
  • پیش‌بینی دمای فردا بر اساس داده‌های تاریخی
  • پیش‌بینی میزان فروش بر اساس هزینه تبلیغات
  • پیش‌بینی مصرف برق بر اساس ساعت روز و فصل
  • رگرسیون خطی ساده: یک متغیر ورودی - پیش‌بینی با یک ویژگی
  • رگرسیون خطی چندگانه: چند متغیر ورودی - پیش‌بینی با چند ویژگی
  • رگرسیون پلی‌نومیال: روابط غیرخطی - استفاده از توان‌های متغیر
  • رگرسیون ریج و لاسو: منظم‌سازی - جلوگیری از بیش‌برازش
  • رگرسیون درخت تصمیم: استفاده از درخت برای پیش‌بینی
  • رگرسیون بردار پشتیبان (SVR): استفاده از تابع هسته

ساده‌ترین نوع رگرسیون است که فقط یک متغیر ورودی (ویژگی) دارد.

y = wx + b
نماد توضیح
y متغیر وابسته (خروجی) - مقداری که می‌خواهیم پیش‌بینی کنیم
x متغیر مستقل (ورودی) - ویژگی
w وزن (Weight) - شیب خط - نشان‌دهنده تأثیر x بر y
b بایاس (Bias) - عرض از مبدأ - مقدار y وقتی x=0

مثال عددی:

فرض کنید می‌خواهیم قیمت خانه را بر اساس متراژ پیش‌بینی کنیم:

اگر w = 500 (هر متراژ ۵۰۰ هزار تومان)

و b = 50,000,000 (قیمت پایه)

آنگاه برای خانه‌ای با ۱۰۰ متر:

قیمت = 500 × 100 + 50,000,000 = 50,050,000 تومان

پیدا کردن بهترین خط:

برای پیدا کردن بهترین w و b، از روش کمترین مربعات (Least Squares) استفاده می‌کنیم:

w = Σ(xi - x̄)(yi - ȳ) / Σ(xi - x̄)2

وقتی چندین ویژگی برای پیش‌بینی داریم، از رگرسیون چندگانه استفاده می‌کنیم.

y = w1x1 + w2x2 + ... + wnxn + b

یا به صورت برداری:

y = WTX + b

مثال:

پیش‌بینی قیمت خانه با ۳ ویژگی:

  • x1 = متراژ (مثلاً ۱۰۰)
  • x2 = تعداد اتاق (مثلاً ۳)
  • x3 = سن ساختمان (مثلاً ۵)

قیمت = 500×100 + 10,000,000×3 - 500,000×5 + 50,000,000

ماتریس طراحی:

اگر n نمونه داده داشته باشیم:

X = [n × (d+1)] matrix

برای مدل کردن روابط غیرخطی از چندجمله‌ای‌ها استفاده می‌کنیم.

y = w0 + w1x + w2x2 + w3x3 + ...

مثال:

رابطه بین سن خودرو و قیمت آن معمولاً خطی نیست:

قیمت = 50,000,000 - 2,000,000x + 50,000x2

در اینجا x سن خودرو است.

نکته مهم:

استفاده از درجه بالای چندجمله‌ای ممکن است باعث بیش‌برازش شود. همیشه از اعتبارسنجی استفاده کنید.

برای جلوگیری از بیش‌برازش، از تکنیک‌های منظم‌سازی (Regularization) استفاده می‌کنیم.

رگرسیون ریج (Ridge):

Loss = MSE + αΣwi2

منظم‌سازی L2 - وزن‌ها را به سمت صفر می‌برد اما هرگز صفر نمی‌کند.

رگرسیون لاسو (Lasso):

Loss = MSE + αΣ|wi|

منظم‌سازی L1 - برخی وزن‌ها را دقیقاً صفر می‌کند (انتخاب ویژگی).

Elastic Net:

Loss = MSE + α1Σ|wi| + α2Σwi2

ترکیب هر دو روش.

CSP (Constraint Satisfaction Problem): مسائلی که در آن‌ها باید متغیرها را طوری مقداردهی کنیم که محدودیت‌هایی را برآورده کنند.

اجزای CSP:

  • متغیرها: X = {X1, X2, ..., Xn}
  • دامنه‌ها: D = {D1, D2, ..., Dn}
  • محدودیت‌ها: C = {C1, C2, ..., Cm}

مثال: جدول زمان‌بندی کلاس‌ها

  • متغیرها: کلاس‌های درس (A, B, C)
  • دامنه: روزهای هفته (شنبه تا پنج‌شنبه)
  • محدودیت‌ها: دو کلاس همزمان نباشند

الگوریتم‌های حل CSP:

  • Backtracking: جستجوی عمقی با بازگشت
  • Arc Consistency (AC-3): سازگاری قوس
  • Min-Conflicts: کمینه کردن تعارضات
  • Genetic Algorithms: الگوریتم ژنتیک

کاربردهای CSP در ML:

  • انتخاب ویژگی
  • تنظیم ابرپارامترها
  • یادگیری ساختار شبکه بیز

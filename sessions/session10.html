جلسه ۱۰: یادگیری باناظر، بی‌ناظر و تقویتی

اهداف یادگیری

  • درک تفاوت انواع یادگیری
  • آشنایی با الگوریتم‌های هر نوع
  • شناخت کاربردهای مناسب هر کدام
یادگیری با داده‌های برچسب‌گذاری شده - مدل از جفت‌های (ورودی، خروجی) یاد می‌گیرد.

ساختار داده:

D = {(x₁, y₁), (x₂, y₂), ..., (xₙ, yₙ)}

که x ورودی و y برچسب (خروجی) است.

دو دسته اصلی:

  • رگرسیون: خروجی پیوسته (عدد)
  • طبقه‌بندی: خروجی گسسته (برچسب)

الگوریتم‌های رایج:

رگرسیون طبقه‌بندی
Linear Regression Logistic Regression
Polynomial Regression K-Nearest Neighbors
Decision Tree Decision Tree
Random Forest Random Forest
SVR SVM
Neural Networks Neural Networks

مثال:

آموزش مدل تشخیص گربه:

  • تصویر (ورودی) → برچسب "گربه" (خروجی)
  • با هزاران مثال، مدل یاد می‌گیرد
  • سپس برای تصویر جدید، برچسب پیش‌بینی می‌کند
یادگیری بدون داده‌های برچسب‌گذاری شده - مدل باید ساختار پنهان در داده‌ها را کشف کند.

دسته‌های اصلی:

  • خوشه‌بندی: گروه‌بندی داده‌های مشابه
  • کاهش بُعد: فشرده‌سازی داده‌ها
  • تشخیص ناهنجاری: پیدا کردن نقاط غیرعادی
  • یادگیری قانون: استخراج قوانین انجمنی

الگوریتم‌های رایج:

خوشه‌بندی کاهش بُعد
K-Means PCA
Hierarchical t-SNE
DBSCAN UMAP
Gaussian Mixture Autoencoder

مثال:

سگمان‌بندی مشتریان:

  • ورودی: اطلاعات خرید مشتریان
  • بدون برچسب!
  • مدل مشتریان مشابه را گروه‌بندی می‌کند
  • مثلاً: گروه "خریداران منظم"، "خریداران گاه‌به‌گاه"
یادگیری از طریق تعامل با محیط و دریافت پاداش یا جریمه

ساختار:

  • Agent (عامل): یادگیرنده
  • Environment (محیط): جایی که عامل در آن عمل می‌کند
  • Action (عمل): تصمیم عامل
  • State (وضعیت): وضعیت فعلی محیط
  • Reward (پاداش): بازخورد از محیط

فرآیند:

State → Action → Reward → New State → ...

مفاهیم کلیدی:

  • Policy (سیاست): استراتژی انتخاب عمل
  • Value Function: ارزش انتظاری هر وضعیت
  • Q-Value: ارزش انتظاری عمل در وضعیت

الگوریتم‌های رایج:

  • Q-Learning
  • Deep Q-Network (DQN)
  • Policy Gradient
  • Actor-Critic
  • Proximal Policy Optimization (PPO)

مثال:

بازی شطرنج:

  • عامل: برنامه شطرنج
  • عمل: حرکت مهره
  • پاداش: +۱ برد، -۱ باخت، ۰ مساوی
  • مدل یاد می‌گیرد کدام حرکات برد را افزایش می‌دهند
ویژگی باناظر بی‌ناظر تقویتی
نوع داده برچسب‌دار بدون برچسب تعاملی
خروجی پیش‌بینی ساختار/الگو سیاست
هدف یادگیری نگاشت کشف الگو بیشینه‌سازی پاداش
مثال تشخیص spam خوشه‌بندی بازی کامپیوتری
ترکیب داده‌های برچسب‌دار و بدون برچسب

چرا مفید است؟

  • برچسب‌گذاری داده‌ها گران و زمان‌بر است
  • معمولاً داده‌های بدون برچسب بیشتر از برچسب‌دار هستند

روش‌ها:

  • Self-Training: استفاده از مدل برای برچسب‌گذاری داده‌های بدون برچسب
  • Co-Training: ترکیب چند مدل
  • Generative Models: مدل‌های مولد
ایجاد برچسب از داده بدون نیاز به انسان

مثال:

  • Word2Vec: پیش‌بینی کلمه بر اساس上下文
  • BERT: پیش‌بینی کلمه masked در جمله
  • Contrastive Learning: تشخیص تصویر مشابه/متفاوت

کاربرد:

بسیار رایج در پردازش زبان طبیعی و بینایی ماشین برای پیش‌آموزش مدل‌های بزرگ.

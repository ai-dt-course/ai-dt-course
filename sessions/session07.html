جلسه ۷: تابع هدف، تابع هزینه و تابع ضرر

اهداف یادگیری

  • درک مفهوم تابع هدف در ML
  • آشنایی با انواع توابع هزینه و ضرر
  • شناخت نحوه بهینه‌سازی مدل
تابع هدف: تابعی که می‌خواهیم آن را بهینه (کمینه یا بیشینه) کنیم.

تفاوت در انواع مسائل:

  • رگرسیون: کمینه‌سازی خطای پیش‌بینی
  • طبقه‌بندی: بیشینه‌سازی دقت یا احتمال
  • یادگیری تقویتی: بیشینه‌سازی پاداش کل

مولفه‌های تابع هدف:

  • تابع هزینه (Loss): اندازه‌گیری خطا برای یک نمونه
  • عبارت منظم‌سازی: جلوگیری از بیش‌برازش
  • عبارت جریمه: اعمال محدودیت‌های اضافی
مثال:

در رگرسیون خطی: کمینه‌سازی MSE

در SVM: کمینه‌سازی حاشیه + جریمه طبقه‌بندی نادرست

تابع هزینه: تابعی که خطای پیش‌بینی مدل را اندازه‌گیری می‌کند. هدف: کمینه‌سازی این تابع

MSE - میانگین مجذور خطا (Mean Squared Error):

MSE = 1/n × Σ(yi - ŷi)2
  • حساس به نقاط پرت
  • همیشه مثبت است
  • یکای آن مجذور یکای اصلی است

RMSE - ریشه میانگین مجذور خطا:

RMSE = √MSE
  • هم‌یکا با متغیر خروجی
  • قابل فهم‌تر از MSE

MAE - میانگین قدرمطلق خطا:

MAE = 1/n × Σ|yi - ŷi|
  • کمتر حساس به نقاط پرت
  • یکای آن همان یکای اصلی است

MSE vs MAE:

ویژگی MSE MAE
حساسیت به پرت بالا پایین
مشتق‌پذیری بله خیر (در صفر)
کاربرد رگرسیون رگرسیون (مقاوم)
مثال عددی:

مقدار واقعی: [10, 20, 30, 40]

پیش‌بینی: [12, 18, 35, 38]

MSE = ((10-12)² + (20-18)² + (30-35)² + (40-38)²)/4 = (4+4+25+4)/4 = 9.25

MAE = (|10-12| + |20-18| + |30-35| + |40-38|)/4 = (2+2+5+2)/4 = 2.75

تابع ضرر: تابع هزینه برای یک نمونه منفرد (در مقابل کل داده‌ها).

رابطه Loss و Cost:

Cost = 1/n × Σ Lossi

انواع Loss:

  • Squared Loss: (y - ŷ)²
  • Absolute Loss: |y - ŷ|
  • Huber Loss: ترکیب MSE و MAE

Cross-Entropy (Entropy متقاطع):

CE = -Σ yi × log(ŷi)

یا برای دو کلاس:

CE = -[y × log(ŷ) + (1-y) × log(1-ŷ)]

Binary Cross-Entropy:

برای یک نمونه با برچسب 1 و پیش‌بینی 0.9:

Loss = -[1×log(0.9) + 0×log(0.1)] = -log(0.9) = 0.105

برای پیش‌بینی 0.1:

Loss = -log(0.1) = 2.302

→ پیش‌بینی اشتباه جریمه سنگین‌تری می‌شود!

Categorical Cross-Entropy:

CE = -Σc yc × log(ŷc)

برای مسائل چند کلاسه.

اضافه کردن جریمه برای جلوگیری از بیش‌برازش.

L1 Regularization (Lasso):

Loss = MSE + α × Σ|wi|

L2 Regularization (Ridge):

Loss = MSE + α × Σwi2

Elastic Net:

Loss = MSE + α1Σ|wi| + α2Σwi2

Dropout:

در شبکه‌های عصبی: حذف تصادفی نورون‌ها در هنگام آموزش.

مقدمه و مفهوم تابع هدف (۸ دقیقه):

با یک سوال شروع کنید: «چطور مدل یادگیری ماشین یاد می‌گیرد؟». جواب این است که مدل سعی می‌کند یک تابع را کمینه یا بیشینه کند - این تابع هدف است. مثال ساده: وقتی دانش‌آموزی امتحان می‌دهد، نمره بالا می‌خواهد (بیشینه کردن). مدل یادگیری ماشین هم همین‌طور است - می‌خواهد خطا کم شود. تأکید کنید که تابع هدف قلب یادگیری ماشین است.

تابع هزینه برای رگرسیون (۱۲ دقیقه):

MSE را با یک مثال عملی توضیح دهید: فرض کنید پیش‌بینی کردیم قیمت خانه ۱۰۰ میلیون ولی قیمت واقعی ۱۲۰ میلیون است. خطا ۲۰ میلیون. MSE می‌آید این را به توان ۲ می‌رساند (۴۰۰ میلیون) - یعنی خطاهای بزرگ خیلی جریمه می‌شوند. MAE را هم توضیح دهید: همان مثال با MAE خطا ۲۰ میلیون است (بدون توان ۲). نکته مهم: MSE به نقاط پرت خیلی حساس است - یک خانه ۱۰ میلیاردی می‌تواند همه پیش‌بینی‌ها را خراب کند.

تابع ضرر (Loss) (۵ دقیقه):

تفاوت Cost و Loss را توضیح دهید: Loss مثل خطای یک دانش‌آموز در یک سؤال است، Cost میانگین خطای همه دانش‌آموزان. در عمل این دو را interchangeably استفاده می‌کنیم. Huber Loss را به عنوان یک راه‌حل میانی معرفی کنید: مثل MSE رفتار می‌کند برای خطاهای کوچک، مثل MAE برای خطاهای بزرگ - یعنی نقاط پرت را جریمه نمی‌کند.

Cross-Entropy (۱۲ دقیقه):

این برای طبقه‌بندی استفاده می‌شود. با یک مثال توضیح دهید: فرض کنید عکسی دارید که واقعاً گربه است (برچسب ۱). مدل می‌گوید ۸۰٪ گربه (۰.۸). Cross-entropy می‌شود -log(0.8) = 0.22 (خطای کم). اگر مدل بگوید ۱۰٪ گربه (۰.۱)، cross-entropy می‌شود -log(0.1) = 2.3 (خطای خیلی زیاد!). نکته کلیدی: پیش‌بینی اشتباه خیلی بیشتر جریمه می‌شود تا پیش‌بینی درست - این انگیزه مدل برای یادگیری است.

منظم‌سازی (۸ دقیقه):

با یک مثال ساده شروع کنید: اگر دانش‌آموزی فقط حفظ کند (بیش‌برازش)، در امتحان جدید.fail می‌شود. منظم‌سازی مثل یک معلم است که می‌گوید «یاد بگیر، نه حفظ». L1 (Lasso) و L2 (Ridge) را با هم مقایسه کنید: L1 برخی وزن‌ها را صفر می‌کند (انتخاب ویژگی)، L2 همه را کوچک می‌کند. Dropout را هم به عنوان یک تکنیک مدرن معرفی کنید که در شبکه‌های عصبی استفاده می‌شود.

جمع‌بندی (۵ دقیقه):

خلاصه: تابع هدف چیزی است که می‌خواهیم بهینه کنیم. برای رگرسیون از MSE/MAE استفاده می‌کنیم، برای طبقه‌بندی از Cross-Entropy. منظم‌سازی برای جلوگیری از بیش‌برازش است. تکلیف: دانشجویان باید یک مثال از تابع هزینه در یک سناریوی واقعی بنویسند.

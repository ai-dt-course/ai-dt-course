جلسه ۷: تابع هدف، تابع هزینه و تابع ضرر

اهداف یادگیری

  • درک عمیق مفهوم تابع هدف در یادگیری ماشین
  • شناخت انواع توابع هزینه و ضرر
  • توانایی انتخاب تابع هزینه مناسب برای هر مسئله
  • درک نقش منظم‌سازی در تابع هدف
  • آشنایی با نحوه بهینه‌سازی مدل
تابع هدف (Objective Function): معیاری که می‌خواهیم آن را بهینه (کمینه یا بیشینه) کنیم. قلب یادگیری ماشین - مدل سعی می‌کند پارامترهایش را طوری تنظیم کند که این تابع بهینه شود.

تعریف کلی:

تابع هدف تابعی است که بر اساس پارامترهای مدل و داده‌ها، یک عدد (معمولاً اسکالر) برمی‌گرداند. مدل سعی می‌کند این عدد را بهینه کند.

تفاوت در انواع مسائل:

نوع مسئله تابع هدف جهت بهینه‌سازی
رگرسیون کمینه‌سازی خطا (MSE, MAE) ↓ کمینه
طبقه‌بندی کمینه‌سازی Cross-Entropy ↓ کمینه
یادگیری تقویتی بیشینه‌سازی پاداش ↑ بیشینه
تحلیل مؤلفه‌ها (PCA) بیشینه‌سازی واریانس ↑ بیشینه

مؤلفه‌های تابع هدف کامل:

J(θ) = L(θ) + λR(θ)

که:

  • J(θ): تابع هدف کامل
  • L(θ): تابع هزینه/ضرر اصلی (خطای پیش‌بینی)
  • R(θ): عبارت منظم‌سازی (Regularization)
  • λ: ضریب اهمیت منظم‌سازی (Hyperparameter)
  • θ: پارامترهای مدل

مثال‌های کاربردی:

رگرسیون خطی:

J = MSE + λΣw²

← خطای پیش‌بینی + جریمه وزن‌های بزرگ

شبکه عصبی:

J = CrossEntropy + λ₁Σw² + λ₂Σ|w|

← خطای طبقه‌بندی + L2 + L1

تابع ضرر (Loss Function): خطا برای یک نمونه منفرد تابع هزینه (Cost Function): میانگین خطا روی کل داده‌ها

رابطه ریاضی:

Cost = (1/n) × Σᵢ Lossᵢ

مثال - ۴ نمونه با Loss های مختلف:

نمونه واقعی پیش‌بینی Loss
۱ ۱۰ ۱۲ (10-12)² = 4
۲ ۲۰ ۱۸ (20-18)² = 4
۳ ۳۰ ۳۵ (30-35)² = 25
۴ ۴۰ ۳۸ (40-38)² = 4
Cost (MSE) (4+4+25+4)/4 = 9.25
در عمل، اصطلاحات Loss و Cost اغلب به جای هم استفاده می‌شوند. ولی از نظر تئوری تفاوت دارند.

تعاریف دقیق‌تر:

  • Loss: برای یک نمونه - مثلاً (y - ŷ)²
  • Cost: میانگین Loss روی n نمونه - (1/n)ΣLᵢ
  • Empirical Risk: همان Cost (نام رسمی‌تر)
  • Objective: ترکیب Cost + Regularization

۳.۱ MSE (Mean Squared Error):

MSE = (1/n) × Σ(yᵢ - ŷᵢ)²

ویژگی‌ها:

  • همیشه مثبت (مربع عدد)
  • مشتق‌پذیر (مهم برای Gradient Descent)
  • حساس به پرت - خطای بزرگ به توان ۲ می‌رسد!
  • یکای آن مربع یکای اصلی
چرا به پرت حساس است:

اگر ۹۹ نمونه خطای ۱ داشته باشند ولی یک نمونه خطای ۱۰۰:

MSE = (99×1² + 100²)/100 = (99 + 10000)/100 = 100.99

← یک پرت، MSE را ۱۰۰ برابر بزرگ کرد!

۳.۲ RMSE (Root Mean Squared Error):

RMSE = √MSE
  • هم‌یکا با متغیر خروجی (مثلاً تومان)
  • قابل فهم‌تر از MSE برای انسان
  • محبوب‌ترین شاخص ارزیابی رگرسیون

۳.۳ MAE (Mean Absolute Error):

MAE = (1/n) × Σ|yᵢ - ŷᵢ|

ویژگی‌ها:

  • مقاوم در برابر پرت (توان ۱، نه ۲)
  • یکای اصلی
  • در صفر مشتق‌ناپذیر (مشکل در GD)

۳.۴ مقایسه MSE و MAE:

ویژگی MSE MAE
حساسیت به پرت بالا (توان ۲) پایین (توان ۱)
مشتق‌پذیری بله (همه جا) خیر (در صفر)
یکا مربع خروجی همان خروجی
بهینه‌سازی آسان (محدب) سخت‌تر
تفسیر سخت‌تر آسان‌تر

۳.۵ Huber Loss (ترکیب MSE و MAE):

Lδ(y, ŷ) = { ½(y - ŷ)²    if |y - ŷ| ≤ δ
              δ(|y - ŷ| - ½δ)    otherwise }
  • برای خطاهای کوچک: مثل MSE (مربع)
  • برای خطاهای بزرگ: مثل MAE (قدرمطلق)
  • مقاوم در برابر پرت + مشتق‌پذیر
  • پارامتر δ تعیین‌کننده نقطه切换
«انتخاب تابع هزینه مثل انتخاب ابزار است - هر کدام برای کار خاصی بهترین هستند.» - الهام از Andrew Ng

۴.۱ Cross-Entropy (آنتروپی متقاطع):

پرکاربردترین تابع هزینه برای طبقه‌بندی. ایده: هرچه پیش‌بینی دورتر از واقعیت باشد، جریمه بیشتر.

Binary Cross-Entropy (دو کلاسه):

CE = -[y·log(ŷ) + (1-y)·log(1-ŷ)]

که y برچسب واقعی (0 یا 1) و ŷ احتمال پیش‌بینی شده برای کلاس 1 است.

مثال - تشخیص بیمار:
واقعی (y) پیش‌بینی (ŷ) Loss توضیح
1 (بیمار) 0.9 -log(0.9) = 0.105 پیش‌بینی خوب - جریمه کم
1 (بیمار) 0.5 -log(0.5) = 0.693 پیش‌بینی متوسط
1 (بیمار) 0.1 -log(0.1) = 2.302 پیش‌بینی بد - جریمه سنگین!
0 (سالم) 0.1 -log(0.9) = 0.105 پیش‌بینی خوب

← هرچه پیش‌بینی اشتباه‌تر، Loss بیشتر!

Categorical Cross-Entropy (چند کلاسه):

CE = -Σc yc·log(ŷc)

که c اندیس کلاس‌ها است. در One-Hot encoding، فقط کلاس واقعی y=1 است و بقیه صفر.

مثال ۳ کلاسه - تشخیص گربه/سگ/اسب:

واقعیت: [1, 0, 0] (گربه)

پیش‌بینی خوب: [0.8, 0.1, 0.1] → CE = -1·log(0.8) = 0.223

پیش‌بینی بد: [0.1, 0.1, 0.8] → CE = -1·log(0.1) = 2.303

۴.۲ Hinge Loss (برای SVM):

L = max(0, 1 - y·f(x))

اگر پیش‌بینی درست با فاصله کافی باشد، Loss = 0. در غیر این صورت، جریمه.

۴.۳ Focal Loss (برای داده نامتوازن):

FL = -α(1-ŷ)γ·log(ŷ)

نمونه‌های سخت را بیشتر جریمه می‌کند. در Detection استفاده می‌شود.

۴.۴ مقایسه توابع هزینه:

تابع کاربرد ویژگی خاص
Binary CE دو کلاسه ساده و محبوب
Categorical CE چند کلاسه استاندارد
Hinge SVM حاشیه‌ای
Focal Detection، نامتوازن تمرکز بر سخت‌ها
منظم‌سازی: اضافه کردن یک عبارت جریمه به تابع هدف برای جلوگیری از بیش‌برازش و بهبود تعمیم مدل.

چرا منظم‌سازی؟

مدل‌های پیچیده با ویژگی‌های زیاد، مستعد بیش‌برازش هستند. منظم‌سازی مدل را به سمت سادگی سوق می‌دهد.

۵.۱ L1 Regularization (Lasso):

J = MSE + α × Σ|wᵢ|
  • جریمه: قدرمطلق وزن‌ها
  • برخی وزن‌ها را دقیقاً صفر می‌کند
  • انتخاب خودکار ویژگی (Feature Selection)
  • مناسب وقتی تعداد کمی ویژگی مهم هستند

۵.۲ L2 Regularization (Ridge):

J = MSE + α × Σwᵢ²
  • جریمه: مربع وزن‌ها
  • وزن‌ها را کوچک می‌کند (هرگز صفر نمی‌کند)
  • مقاوم در برابر همبستگی بین ویژگی‌ها
  • محاسبات ساده‌تر

۵.۳ Elastic Net (ترکیب):

J = MSE + α₁ × Σ|wᵢ| + α₂ × Σwᵢ²

۵.۴ Dropout (برای شبکه عصبی):

در هر مرحله آموزش، درصدی از نورون‌ها به طور تصادفی خاموش می‌شوند. این کار:

  • جلوگیری از وابستگی به نورون‌های خاص
  • ایجاد تعمیم بهتر
  • مثل آموزش چندین مدل به طور همزمان

۵.۵ Early Stopping:

توقف آموزش وقتی خطای validation شروع به افزایش کرد.

تأثیر α (ضریب منظم‌سازی):

α تأثیر خطر
0 بدون منظم‌سازی بیش‌برازش
کوچک منظم‌سازی ملایم کم
متوسط تعادل خوب کم
بزرگ منظم‌سازی شدید زیربرازش

هدف: پیدا کردن θ* که J(θ) را کمینه کند.

۶.۱ روش‌های حل:

۱. حل تحلیلی (Closed-form):

برای MSE می‌توان معادله نرمال را حل کرد:

W = (XTX)-1 XTy

مناسب برای داده‌های کوچک. مشکل: محاسبه معکوس ماتریس برای داده‌های بزرگ گران.

۲. Gradient Descent:

تکرار شونده: در خلاف جهت گرادیان قدم بردار.

θ := θ - α · ∇J(θ)

که α نرخ یادگیری است. در جلسه بعد مفصل توضیح داده می‌شود.

۳. Stochastic Gradient Descent (SGD):

گرادیان روی یک نمونه (یا batch کوچک) محاسبه می‌شود.

  • سریع‌تر برای داده‌های بزرگ
  • نویزدارتر
  • می‌تواند از local minima فرار کند

۴. Mini-batch Gradient Descent:

ترکیبی از GD و SGD: batch های کوچک (32, 64, 128).

۵. Adam Optimizer:

تطبیقی - برای هر پارامتر نرخ یادگیری جداگانه. در یادگیری عمیق بسیار محبوب.

۶.۲ چالش‌های بهینه‌سازی:

  • Local Minima: مدل در نقطه کمینه محلی گیر می‌کند
  • Saddle Points: نقطه‌ای که در بعضی جهت‌ها min و بعضی max
  • Plateau: ناحیه صاف که گرادیان ≈ 0
  • Vanishing/Exploding Gradients: در شبکه‌های عمیق

۶.۔ ویژگی‌های تابع هدف خوب:

  • محدب (Convex): فقط یک نقطه کمینه سراسری (مثل MSE در رگرسیون خطی)
  • مشتق‌پذیر: برای Gradient Descent
  • جریمه متناسب: خطای بیشتر، جریمه بیشتر
مقدمه و مفهوم تابع هدف (۸ دقیقه):

با یک سوال شروع کنید: «چطور مدل یادگیری ماشین یاد می‌گیرد؟». جواب این است که مدل سعی می‌کند یک تابع را کمینه یا بیشینه کند - این تابع هدف است. مثال ساده: وقتی دانش‌آموزی امتحان می‌دهد، نمره بالا می‌خواهد (بیشینه کردن). مدل یادگیری ماشین هم همین‌طور است - می‌خواهد خطا کم شود. تأکید کنید که تابع هدف قلب یادگیری ماشین است.

تابع هزینه برای رگرسیون (۱۲ دقیقه):

MSE را با یک مثال عملی توضیح دهید: فرض کنید پیش‌بینی کردیم قیمت خانه ۱۰۰ میلیون ولی قیمت واقعی ۱۲۰ میلیون است. خطا ۲۰ میلیون. MSE می‌آید این را به توان ۲ می‌رساند (۴۰۰ میلیون) - یعنی خطاهای بزرگ خیلی جریمه می‌شوند. MAE را هم توضیح دهید: همان مثال با MAE خطا ۲۰ میلیون است (بدون توان ۲). نکته مهم: MSE به نقاط پرت خیلی حساس است - یک خانه ۱۰ میلیاردی می‌تواند همه پیش‌بینی‌ها را خراب کند. از تخته برای نوشتن فرمول استفاده کنید.

تابع ضرر (Loss) (۵ دقیقه):

تفاوت Cost و Loss را توضیح دهید: Loss مثل خطای یک دانش‌آموز در یک سؤال است، Cost میانگین خطای همه دانش‌آموزان. در عمل این دو را interchangeably استفاده می‌کنیم. Huber Loss را به عنوان یک راه‌حل میانی معرفی کنید: مثل MSE رفتار می‌کند برای خطاهای کوچک، مثل MAE برای خطاهای بزرگ - یعنی نقاط پرت را جریمه نمی‌کند.

Cross-Entropy (۱۲ دقیقه):

این برای طبقه‌بندی استفاده می‌شود. با یک مثال توضیح دهید: فرض کنید عکسی دارید که واقعاً گربه است (برچسب ۱). مدل می‌گوید ۸۰٪ گربه (۰.۸). Cross-entropy می‌شود -log(0.8) = 0.22 (خطای کم). اگر مدل بگوید ۱۰٪ گربه (۰.۱)، cross-entropy می‌شود -log(0.1) = 2.3 (خطای خیلی زیاد!). نکته کلیدی: پیش‌بینی اشتباه خیلی بیشتر جریمه می‌شود تا پیش‌بینی درست - این انگیزه مدل برای یادگیری است. لگاریتم در 0 = -∞ است - به همین دلیل اگر مدل احتمال 0 بدهد، Loss بی‌نهایت می‌شود!

منظم‌سازی (۸ دقیقه):

با یک مثال ساده شروع کنید: اگر دانش‌آموزی فقط حفظ کند (بیش‌برازش)، در امتحان جدید.fail می‌شود. منظم‌سازی مثل یک معلم است که می‌گوید «یاد بگیر، نه حفظ». L1 (Lasso) و L2 (Ridge) را با هم مقایسه کنید: L1 برخی وزن‌ها را صفر می‌کند (انتخاب ویژگی)، L2 همه را کوچک می‌کند. Dropout را هم به عنوان یک تکنیک مدرن معرفی کنید که در شبکه‌های عصبی استفاده می‌شود.

جمع‌بندی (۵ دقیقه):

خلاصه: تابع هدف چیزی است که می‌خواهیم بهینه کنیم. برای رگرسیون از MSE/MAE استفاده می‌کنیم، برای طبقه‌بندی از Cross-Entropy. منظم‌سازی برای جلوگیری از بیش‌برازش است. تکلیف: دانشجویان باید یک مثال از تابع هزینه در یک سناریوی واقعی بنویسند. جلسه بعد Gradient Descent را یاد می‌گیریم - روش بهینه‌سازی تابع هدف.

فصل هفتم: تابع هدف، تابع هزینه و تابع ضرر

۷.۱ تابع هدف (Objective Function)

تابع هدف تابعی است که می‌خواهیم آن را بهینه (کمینه یا بیشینه) کنیم. در یادگیری ماشین، هدف این است که پارامترهای مدل را طوری تنظیم کنیم که این تابع بهینه شود.

تفاوت در انواع مسائل:

  • رگرسیون: کمینه‌سازی خطای پیش‌بینی (MSE, MAE)
  • طبقه‌بندی: کمینه‌سازی Cross-Entropy
  • یادگیری تقویتی: بیشینه‌سازی پاداش کل

شکل کلی تابع هدف:

J(θ) = L(θ) + λR(θ)

که L تابع هزینه، R منظم‌سازی، λ ضریب منظم‌سازی و θ پارامترها هستند.

۷.۲ تفاوت Loss و Cost

تابع ضرر (Loss): خطا برای یک نمونه منفرد

تابع هزینه (Cost): میانگین Loss روی کل داده‌ها

Cost = (1/n) × Σ Lossᵢ

۷.۳ توابع هزینه رگرسیون

MSE (Mean Squared Error):

MSE = (1/n) × Σ(yᵢ - ŷᵢ)²

  • همیشه مثبت
  • مشتق‌پذیر
  • حساس به نقاط پرت
  • یکای مربع

RMSE (Root MSE):

RMSE = √MSE - هم‌یکا با خروجی

MAE (Mean Absolute Error):

MAE = (1/n) × Σ|yᵢ - ŷᵢ|

  • مقاوم در برابر پرت
  • یکای اصلی

Huber Loss:

ترکیب MSE و MAE - مقاوم در برابر پرت + مشتق‌پذیر

Binary Cross-Entropy:

CE = -[y·log(ŷ) + (1-y)·log(1-ŷ)]

Categorical Cross-Entropy (چند کلاسه):

CE = -Σ yc·log(ŷc)

Hinge Loss (SVM):

تمرکز بر نمونه‌های سخت

۷.۵ منظم‌سازی (Regularization)

اضافه کردن جریمه برای جلوگیری از بیش‌برازش.

L1 (Lasso):

Loss = MSE + α × Σ|wᵢ|

انتخاب خودکار ویژگی (صفر کردن برخی وزن‌ها)

L2 (Ridge):

Loss = MSE + α × Σwᵢ²

کوچک کردن همه وزن‌ها

Elastic Net:

ترکیب L1 و L2

Dropout (شبکه عصبی):

حذف تصادفی نورون‌ها در آموزش

۷.۶ بهینه‌سازی تابع هدف

روش‌های حل:

  • حل تحلیلی: Closed-form (فقط برای MSE در رگرسیون خطی)
  • Gradient Descent: تکرار شونده
  • SGD: سریع‌تر با نمونه‌های تصادفی
  • Adam: تطبیقی، محبوب در یادگیری عمیق

خلاصه فصل:

  1. تابع هدف چیزی است که می‌خواهیم بهینه کنیم
  2. Loss برای یک نمونه، Cost میانگین همه
  3. برای رگرسیون: MSE (حساس به پرت) یا MAE (مقاوم)
  4. برای طبقه‌بندی: Cross-Entropy
  5. منظم‌سازی برای جلوگیری از بیش‌برازش ضروری است

پروژه نیم‌ترم: پیش‌بینی بار (Load Forecasting)

مهلت تحویل: هفته دهم ترم
وزر نمره: ۱۰٪

هدف پروژه

پیاده‌سازی یک مدل یادگیری ماشین برای پیش‌بینی مصرف برق (بار) با استفاده از داده‌های تاریخی.

توضیحات پروژه

  • پیش‌بینی بار روزانه بر اساس داده‌های تاریخی
  • استفاده از ویژگی‌های زمانی (ساعت، روز، ماه، فصل)
  • مقایسه چند مدل رگرسیون

مجموعه داده

از داده‌های مصرف برق یا گاز طبیعی استفاده کنید:

  • UCI Energy Consumption Dataset
  • Kaggle Energy Demand Forecasting
  • داده‌های شرکت توزیع برق (در صورت دسترسی)

مراحل پروژه

  • ۱. جمع‌آوری و بارگذاری داده
  • ۲. تحلیل اکتشافی داده (EDA)
  • ۳. پیش‌پردازش و مهندسی ویژگی
  • ۴. مدل‌سازی (حداقل ۳ مدل)
  • ۵. ارزیابی و مقایسه مدل‌ها
  • ۶. نتیجه‌گیری و پیشنهادات
